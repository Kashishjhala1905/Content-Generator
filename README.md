# Academic Content Generator

A lightweight browser-based project that generates structured academic research paper content from a user-provided topic.

## Features

- Generates the required sections:
  - Title
  - Abstract
  - Introduction
  - Literature Review
  - Methodology
  - Results & Discussion
  - Conclusion
- Uses a formal academic tone with simple professional English.
- Generates content in English, Hindi, Gujarati, Marathi, Tamil, Telugu, Punjabi, Spanish, French, or German.
- Adds topic-specific research angles, evidence types, expected challenges, and outcomes so different topics produce different drafts.
- Supports field-specific wording for general research, technology, education, healthcare, business, environment, and social science.
- Includes copy and download actions for the generated draft.

## How to Use

Run the project on localhost:

```bash
npm start
```

Then open `http://localhost:3000` in a browser, enter a research topic, choose an academic field, select an output language, and click **Generate Content**.

You can also open `index.html` directly in a browser if you do not need localhost.
